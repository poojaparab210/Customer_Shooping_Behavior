# Customer Shopping Behavior

**Author:** Pooja Parab

## 📌 Overview

The **Customer Shopping Behavior** project focuses on analyzing customer shopping data to identify purchasing patterns, understand customer preferences, and generate meaningful business insights.

The project follows an end-to-end data analysis workflow, starting with loading and exploring the dataset in Python, cleaning and preprocessing the data, performing SQL analysis using PostgreSQL, and building an interactive dashboard in Power BI.

The objective is to transform raw customer data into actionable insights that can support data-driven business decisions.

## 📂 Dataset

The project uses a customer shopping behavior dataset containing information related to customer purchases and shopping patterns.

The dataset is used to:
- Understand customer purchasing behavior.
- Identify trends and patterns in shopping activities.
- Analyze customer-related metrics.
- Generate insights to support business decisions.

## 🛠️ Tools and Technologies

The following tools and technologies are used in this project:

- **Python:** Data loading, cleaning, preprocessing, and Exploratory Data Analysis (EDA).
- **Pandas & NumPy:** Data manipulation and analysis.
- **Matplotlib & Seaborn:** Data visualization and exploratory analysis.
- **PostgreSQL:** Database management and SQL-based data analysis.
- **Power BI:** Interactive dashboard development and data visualization.
- **Jupyter Notebook:** Python-based analysis and documentation.

## 🔄 Project Steps

- Used filtering, aggregation, grouping, and other SQL operations to extract insights.
- Analyzed relevant business metrics.

### 5. Power BI Dashboard
- Connected the analyzed data to Power BI.
- Created an interactive dashboard to present key insights.
- Used visualizations and interactive elements to make the analysis easier to understand.

### 6. Project Report
- Prepared a project report documenting the analysis.
- Summarized the workflow, findings, and business recommendations.
